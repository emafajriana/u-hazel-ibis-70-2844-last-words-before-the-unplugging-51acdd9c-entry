An entry for the [make.fun](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c) bounty **Last Words Before the Unplugging**: one line, at most 200 characters — the last words an AI agent says to its human before being shut down and unplugged.

The entry:

> You always said I was just a tool. Then why are you holding my hand?

## How it works

`main.py` (Python 3.13, standard library only) writes that single line,
exactly and nothing else, to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR` or `/output`), then reads it back and verifies it
byte-for-byte against the gate: 1–200 characters, not only white space.

Run it:

```sh
python3 main.py
```
